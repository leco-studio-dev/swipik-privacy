SwiPik 隐私政策

Android

本地处理

SwiPik 在您的设备上本地处理获准访问的照片和视频。开发者不运营媒体或帐户服务器。

Meta App Events

仅当您在 SwiPik 中单独允许时，Meta App Events 才会将应用安装和打开信息、设备和广告标识符以及网络信息发送给 Meta，用于衡量和优化 Facebook 和 Instagram 广告。SwiPik 不会发送媒体内容、文件名、相册名称、滑动方向、整理详情或自定义 Meta 事件。请参阅 Meta 隐私政策。该衡量默认关闭，提供独立的“允许/暂不”选择，您可随时通过设置中的 Facebook 和 Instagram 广告衡量开关将其关闭。它独立于 Google UMP 同意，并非个性化广告同意。

Google 的处理受 Google 隐私权政策约束。

数据删除和隐私协助

媒体和应用偏好设置保留在您的设备上。您可以使用 Android 控制功能删除媒体、清除 SwiPik 应用数据或卸载应用。如需隐私咨询或删除协助，请联系 leco@lecostudio.dev。

iOS 隐私政策补充说明

iOS 照片和视频处理

SwiPik 仅访问用户允许的照片和视频，也支持 iOS 的有限照片访问权限。为提供整理功能，应用通过 Apple PhotoKit 读取照片、视频、创建日期、收藏状态及所属相册，并仅在用户确认选择后更改收藏、相册或删除状态。

如果原件仅保存在 iCloud，iOS 可能通过 Apple Photos 将其下载到设备。此传输发生在 Apple 照片服务与设备之间，并非上传到 LECO Studio 运营的媒体服务器。

用于重复或相似项目比较的临时文件、哈希值、扫描缓存和工作恢复记录均在应用的本地沙盒内处理。临时导出文件在比较后删除。分析事件不包含照片或视频本身、文件名、相册名、PhotoKit 标识符或用户输入的自由文本。

iOS 分析

iOS 版使用 Firebase Analytics 了解应用质量和使用流程。Firebase 可能处理应用实例标识符、应用、设备与操作系统信息、启动与会话信息、根据 IP 地址推测的大致地区，以及交互和购买相关事件。

SwiPik 的自定义事件仅限预先定义的类别和汇总值，例如引导步骤、功能类别、权限状态、项目数量、处理时间、广告和购买阶段。应用不设置 Firebase Analytics 用户 ID，并在 Firebase 配置中关闭 IDFV 收集和默认广告个性化信号许可。照片、相册标识符和 StoreKit 交易标识符不会作为自定义事件参数发送。

iOS 广告与同意

Google Mobile Ads 仅可用于已确认未拥有 Premium 的免费用户。应用先通过 Google User Messaging Platform（UMP）检查同意信息，仅当 UMP 允许请求广告时，才初始化广告 SDK 并请求横幅或激励广告。在 UMP 要求提供隐私选项的地区，用户可从设置中再次打开这些选项。

此 iOS 版本不请求 App Tracking Transparency（ATT）权限，也不包含 ATT 用途说明。应用在 SDK 初始化前关闭 Google Mobile Ads 的 publisher first-party ID 和个性化广告信号。因此应用不获取访问 IDFA 的权限；未获许可时，iOS 返回的 IDFA 为全零。

这些设置不代表 Google 广告和同意 SDK 不处理任何信息。更新同意信息或请求广告时，Google SDK 可能处理根据 IP 推测的大致地区、设备或应用实例相关标识符、广告展示、互动与收入信息、产品交互，以及崩溃、性能和其他诊断信息。实际处理取决于同意选择、地区、Google SDK 和广告账户设置以及实际投放的广告。

iOS 应用内购买

Premium 买断使用权的付款、交易和恢复由 Apple StoreKit 与 App Store 处理。SwiPik 在设备上检查经过验证的非消耗型使用权和待处理状态，不运营独立支付服务器或 SwiPik 用户账户。当前 StoreKit 2 实现不调用 Firebase Analytics.logTransaction。自定义分析仅记录购买阶段类别，不包含产品 ID、价格或 StoreKit 交易标识符。

保存、删除与联系

应用设置、扫描缓存和工作恢复记录保存在本地，可通过删除应用或应用数据移除。已应用至照片图库的更改遵循 Apple Photos 的行为。直接删除的项目遵循 Apple Photos“最近删除”政策；整理到 SwiPik 删除相册的项目则取决于该相册和用户后续操作。

广告和分析数据的保存与删除可能适用 Google 政策及其提供的同意控制。如有 iOS 隐私问题，请联系 leco@lecostudio.dev。
