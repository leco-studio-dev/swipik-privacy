SwiPik 隱私權政策

Android

本機處理

SwiPik 在您的裝置上本機處理獲准存取的相片和影片。開發者不營運媒體或帳戶伺服器。

Meta App Events

僅當您在 SwiPik 中另行允許時，Meta App Events 才會將應用程式安裝和開啟資訊、裝置和廣告識別碼以及網路資訊傳送給 Meta，用於衡量和最佳化 Facebook 和 Instagram 廣告。SwiPik 不會傳送媒體內容、檔案名稱、相簿名稱、滑動方向、整理細節或自訂 Meta 事件。請參閱 Meta 隱私權政策。此衡量預設關閉，提供獨立的「允許/暫不」選擇，您可隨時透過設定中的 Facebook 和 Instagram 廣告衡量開關將其關閉。它獨立於 Google UMP 同意，並非個人化廣告同意。

Google 的處理受 Google 隱私權政策約束。

資料刪除和隱私協助

媒體和應用程式偏好設定保留在您的裝置上。您可以使用 Android 控制功能刪除媒體、清除 SwiPik 應用程式資料或解除安裝應用程式。如需隱私諮詢或刪除協助，請聯絡 leco@lecostudio.dev。

iOS 隱私權政策補充說明

iOS 相片和影片處理

SwiPik 僅存取使用者允許的相片和影片，也支援 iOS 的有限相片存取權限。為提供整理功能，應用程式透過 Apple PhotoKit 讀取相片、影片、建立日期、喜好項目狀態及所屬相簿，並僅在使用者確認選擇後變更喜好項目、相簿或刪除狀態。

如果原始檔僅儲存在 iCloud，iOS 可能透過 Apple Photos 將其下載到裝置。此傳輸發生在 Apple 相片服務與裝置之間，並非上傳至 LECO Studio 營運的媒體伺服器。

用於重複或相似項目比較的暫存檔、雜湊值、掃描快取和作業復原紀錄均在應用程式的本機沙盒內處理。暫時匯出檔案在比較後刪除。分析事件不包含相片或影片本身、檔案名稱、相簿名稱、PhotoKit 識別碼或使用者輸入的自由文字。

iOS 分析

iOS 版使用 Firebase Analytics 瞭解應用程式品質和使用流程。Firebase 可能處理應用程式執行個體識別碼、應用程式、裝置與作業系統資訊、啟動與工作階段資訊、根據 IP 位址推估的大致地區，以及互動和購買相關事件。

SwiPik 的自訂事件僅限預先定義的類別和彙總值，例如引導步驟、功能類別、權限狀態、項目數量、處理時間、廣告和購買階段。應用程式不設定 Firebase Analytics 使用者 ID，並在 Firebase 設定中關閉 IDFV 收集和預設廣告個人化信號許可。相片、相簿識別碼和 StoreKit 交易識別碼不會作為自訂事件參數傳送。

iOS 廣告與同意

Google Mobile Ads 僅可用於已確認未擁有 Premium 的免費使用者。應用程式先透過 Google User Messaging Platform（UMP）檢查同意資訊，僅當 UMP 允許請求廣告時，才初始化廣告 SDK 並請求橫幅或獎勵廣告。在 UMP 要求提供隱私權選項的地區，使用者可從設定再次開啟這些選項。

此 iOS 版本不請求 App Tracking Transparency（ATT）權限，也不包含 ATT 用途說明。應用程式在 SDK 初始化前關閉 Google Mobile Ads 的 publisher first-party ID 和個人化廣告信號。因此應用程式不取得存取 IDFA 的權限；未獲許可時，iOS 傳回的 IDFA 為全零。

這些設定不代表 Google 廣告和同意 SDK 不處理任何資訊。更新同意資訊或請求廣告時，Google SDK 可能處理根據 IP 推估的大致地區、裝置或應用程式執行個體相關識別碼、廣告曝光、互動與收益資訊、產品互動，以及當機、效能和其他診斷資訊。實際處理取決於同意選擇、地區、Google SDK 和廣告帳戶設定以及實際投放的廣告。

iOS App 內購買

Premium 買斷使用權的付款、交易和回復由 Apple StoreKit 與 App Store 處理。SwiPik 在裝置上檢查經驗證的非消耗型使用權和待處理狀態，不營運獨立付款伺服器或 SwiPik 使用者帳戶。目前 StoreKit 2 實作不呼叫 Firebase Analytics.logTransaction。自訂分析僅記錄購買階段類別，不包含產品 ID、價格或 StoreKit 交易識別碼。

保存、刪除與聯絡

應用程式設定、掃描快取和作業復原紀錄儲存在本機，可透過刪除應用程式或應用程式資料移除。已套用至相片圖庫的變更遵循 Apple Photos 的行為。直接刪除的項目遵循 Apple Photos「最近刪除」政策；整理至 SwiPik 刪除相簿的項目則取決於該相簿和使用者後續操作。

廣告和分析資料的保存與刪除可能適用 Google 政策及其提供的同意控制。如有 iOS 隱私權問題，請聯絡 leco@lecostudio.dev。
